# 里程碑与验收标准

## M0：接口冻结

- 模型合同所有 `TBD` 均有负责人和截止日期；关键字段全部填写。
- 双方在同一装配图上确认坐标系、零位、关节正方向和折叠方向。
- 网格单位和缩放经过一次自动或人工尺寸校验。

## M1：可视化与基础控制

- MuJoCo 能无报错加载机器人和地面场景。
- 关节数量、名称、范围与模型合同一致。
- 可通过配置文件指定全部关节目标位置。
- 默认站立 10 秒不出现穿模、数值发散或非预期翻倒。
- 运行产生日志，至少记录时间、base 位姿、关节位置/速度、控制量和接触状态。

## M2：平面行走与位姿控制

- 在指定平面上完成不少于 1 m 的稳定前进。
- 能跟踪给定的 base 高度、横滚、俯仰和偏航目标。
- 记录速度误差、姿态误差、足端滑移和控制峰值。
- 步态参数可从 YAML 加载，无需改源代码。

## M3：墙面附着与运动

- 六足吸附状态可独立控制和观测。
- 控制器只在确认吸附后切换支撑相。
- 给定安全系数下，机器人能在竖直墙面维持姿态并完成至少一个步态周期。
- 明确吸附力不足、接触丢失和命令超时的处理方式。

## M4：平面—墙面切换

- 完整流程可由状态机自动执行，而非手工拖动模型。
- 每一阶段的目标、阈值、超时和回退参数均可导出。
- 连续成功 10 次，报告成功率、最大姿态误差、最大足端滑移和总耗时。
- 同一控制序列能够被回放，并保留向实体机器人控制量映射的字段。

## 演示包最低内容

- Git 提交号；
- MuJoCo 与 Python 版本；
- 启动命令；
- 配置文件；
- 原始日志；
- 30~90 秒演示视频；
- 一页结果摘要及已知限制。
